## 2026-10-12 · «Добавить Apple ID» при активной общей полке отдаёт новый Apple ID общему участнику [P1]
**Context:** ревью ветки `multi-signin` (spec 2026-10-12 §4, §6.3); `appshelf/web/accounts.py` (`/apple/add`), `appshelf/web/signin.py` (`decide`, `register`), подсказка в `appshelf/web/templates/login.html`.
**What:** новый для сервера Apple ID из «Добавить» достаётся человеку активной полки. Если активна полка общего Apple ID (или в браузере вошёл только он), личный Apple ID становится полкой общего участника: её видит, публикует и удаляет каждый, кто входит общим Apple ID, а добавивший сохраняет доступ к общей полке и после смены её пароля с «Выйти на всех устройствах». Вернуть Apple ID себе в панели нельзя — только удалить полку. Форма называет получателя лишь при двух и более вошедших, имя участника может совпадать с именем другого, а `GET /acct/<id>` меняет активную полку и по ссылке с чужого сайта.
**Proposal:** нужно решение владельца. Минимум — подсказка всегда называет получателя и его активную полку и говорит о последствии («её увидит каждый, кто входит Apple ID этого участника; отдельным участником Apple ID становится по приглашению»), та же фраза в README. Строже — спрашивать на форме, к кому добавить, или не добавлять новые Apple ID участнику, отмеченному как общий.
**Status:** open
