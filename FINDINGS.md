## 2026-11-07 · Apple отклоняет новый вход, рабочая сессия магазина сохранена [P2]
**Context:** Пять `POST /login` завершились 400, форма показала `edge_rejected`. Существующая сессия владельца успешно читает покупки; запрос конфигурации Apple получает 200.
**What:** На подписанные диагностические запросы без настоящих учётных данных Apple нестабильно возвращает 204/301/403/404, иногда HTML вместо plist; HTTP 301 не содержит Location. Запасной маршрут тоже получает отказы. Изоляция cookies не устранила отказ в контрольных пробах; эта неподтверждённая правка откачена. Точная причина отказа реального входа остаётся неподтверждённой. Безопасная диагностика кода и HTTP-статуса выложена; необоснованное утверждение о блокировке адреса убрано. Запасная ссылка выдана.
**Proposal:** Нужна одна повторная попытка обычного входа владельцем через форму; пароль нигде не сохраняется и агенту не передаётся. По её журналу проверить реальный ответ Apple и выбрать дальнейший фикс. Повторять диагностические запросы с вымышленными аккаунтами не требуется: они не подтверждают работу настоящего входа.
**Status:** open
