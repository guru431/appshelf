## 2026-11-08 · Новый вход Apple отклоняется при рабочей сохранённой сессии [P2]
**Context:** Участник сообщил об отказе входа с телефона; диагностика реальных попыток выполнена 2026-11-08.
**What:** Сначала общий сервер магазина отвечал пустым HTTP 204. Обновление адреса и формата запроса не решило вход: native endpoint вернул 204, затем 301 без Location либо HTML 500. Исходный бинарник до диагностики датирован 2026-10-09; последняя успешная авторизация этого аккаунта — 2026-10-13. Исходники клиента запросов и Python-обёртки за этот период не менялись, прокси Apple не включён. Причина первоначального отказа пока не установлена.
**Proposal:** Установлен полный механизм входа из закреплённого upstream `001d889` с локальной проверкой устройства. Адаптер принимает пароль только через stdin и импортирует результат в прежний шифрованный формат без пароля; неподходящий идентификатор и данные с паролем отклоняются. Пройдены Go- и C++-контракты, проверка прав исполняемого файла и сохранности аккаунта; действующая сессия читает 23 покупки. Требуется подтверждение обычного входа участника; до него инцидент открыт. Само наличие исправления upstream не доказывает причину этого отказа.
**Status:** open
