## 2026-10-13 · «Установить» не обновляет уже установленное приложение [P2]
**Context:** жалоба владельца и снимок экрана iPhone: «Установить» в каталоге при установленной старой версии того же приложения.
**What:** iOS отказывает до скачивания: «… is Already Installed. To install this app, delete … from your device and try again». Запрет системный: после атак Masque `itms-services` не ставит поверх копии из App Store, а в момент нажатия iOS видит только `bundle-identifier` из manifest, поэтому тот же Apple ID и номер версии не помогают. README («удалённое из App Store обновляют только отсюда») об этом молчит. Подмена `bundle-identifier` в manifest не годится: iOS 16+ сверяет его с содержимым IPA и оставляет значок-пустышку.
**Proposal:** 1) проверить на телефоне «Сгрузить приложение» → «Установить»: данные при сгрузке остаются, но пройдёт ли проверка — неизвестно; пробовать на приложении, которое ещё есть в App Store (удалённое после сгрузки значком не восстановить). Сработает — подсказка в каталоге и README. 2) Не сработает — ссылка «Скачать IPA» в каталоге и раздел README про установку поверх с компьютера (`ideviceinstaller upgrade`, iMazing: идёт мимо проверки, данные сохраняются). 3) В обоих случаях сказать в README и каталоге, что поверх установленного iOS по кнопке не ставит.
**Status:** open
