По ссылке

Понимает страницы приложений Google Play, AppGallery (или ID вида C102312137), F-Droid, IzzyOnDroid, APKPure, RuStore и репозитории GitHub — источник и пакет берутся из адреса. Иначе ссылка — на сам файл .apk на сайте банка или разработчика, только https: ночью полка проверяет, не сменился ли файл. Для F-Droid автоматически проверяется и архив. Выбранная версия F-Droid или IzzyOnDroid сохраняется без обновления; репозиторий GitHub следует последнему стабильному выпуску с APK. Адреса локальной сети не принимаются.
