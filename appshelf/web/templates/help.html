Версии и обновления

«⋯» → «Закрепить»: версия переживёт следующие обновления («сохранённая») и ставится так же. Файл сохранён, но откат не гарантирован: старая версия может не принять данные, оставленные новой, — ставить её поверх них на свой риск.

«⋯» → «Проверить обновление»: последняя версия приложения сразу, не дожидаясь ночи; не отдаст Apple — текущая останется и ставится. «Проверить обновления всех» над каталогом — то же для всех приложений полки. «Проверено …» у карточки — о полке, не о версии на телефоне.

Выключите «Настройки → App Store → Сгружать неиспользуемые»: выгруженное приложение App Store не вернёт.

Удалённые из App Store

Банки и их клоны, VK, МАКС и другие удалённые приложения Apple не показывает в истории покупок, но то, что есть у вашего Apple ID, скачивается. Раздел «Удалённые» сверяет справочник с аккаунтом: «Проверить новые» — сразу, всё заново — ночная проверка раз в неделю.

Версии и источники

Выберите сохранённую версию в списке на карточке; по умолчанию выбрана последняя. «Сменить источник» — версии остаются; новая версия из другого источника с другой подписью ждёт «Принять новую подпись».

После успешного обновления остаются текущая, предыдущая и одна закреплённая версия. Закрепление защищает от автоудаления; старую версию можно удалить вручную.

Устройство

Профиль «Android и архитектура» в Настройках хранится только в этом браузере: карточки показывают, подходит ли APK по известным требованиям, а поиск предлагает подходящую сборку F-Droid.

«Скачать APK» запоминает версию в этом браузере: карточка покажет, что вы скачивали, а переключатель «Есть обновление для меня» над списком оставит только приложения, у которых на полке версия новее.

Добавить на Android

Поиск

Ищет в RuStore, F-Droid, его архиве и IzzyOnDroid, Google Play, AppGallery и APKPure, на личной полке — и в 4PDA вашим аккаунтом. Выберите источник: сборки одного приложения могут отличаться подписью и функциями. AppGallery и APKPure проверяются по найденным пакетам. Если приложение приходит набором файлов, проверяются ссылки автора на GitHub в описании и на его сайте. Поиска по всему GitHub нет.

RuStore — универсальный APK, подпись сверяется с той, что сообщает RuStore. Платные без входа в RuStore не скачать.

На 4PDA найдите тему, затем выберите подходящий APK; аккаунт 4PDA подключается в «Аккаунтах».

Ссылка

Понимает страницы приложений Google Play, AppGallery (или ID вида C102312137), F-Droid, IzzyOnDroid, APKPure, RuStore и репозитории GitHub, Codeberg и GitLab — источник и пакет берутся из адреса. Иначе ссылка — на сам файл .apk на сайте банка или разработчика, только https: ночью полка проверяет, не сменился ли файл. Для F-Droid автоматически проверяется и архив. Выбранная версия F-Droid или IzzyOnDroid сохраняется без обновления; репозиторий GitHub, Codeberg или GitLab следует последнему стабильному выпуску с APK. Адреса локальной сети не принимаются.

Ссылку на отдельный APK 4PDA тоже можно вставить сюда (личная полка): скачивание использует ваш подключённый аккаунт 4PDA. Выбранное вложение сохраняется без автоматического обновления.

APKPure распространял подменённые APK: если пакета нет в RuStore, подпись не с чем сверить — такую ссылку нужно подтвердить отдельной галочкой.

Google Play

Нужен Google-аккаунт, подключённый к Google Play на странице «Аккаунты» (для публичной полки — аккаунт владельца); для подключения понадобится компьютер. До добавления проверяются доступность приложения и доставка одним APK. Набор файлов (split APK) или некупленное платное приложение не добавится. Купленное — только на свою полку; без Play Store на телефоне оно может не пройти проверку лицензии.

Свой файл

Один целый APK до 1 ГБ. Наборы (split APK, XAPK, APKS) из браузера не ставятся. Ночью свой файл не обновляется — новую версию загрузите на карточку («⋯» → «Сменить источник»). Большой файл уходит частями: прерванную загрузку можно продолжить, полученные части хранятся 7 дней.
